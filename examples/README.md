# Examples for the `tedious-plus` package

How to run the example programs:

1. Install [Node](https://nodejs.org) version 24 or later, with `npm`.
2. Download the files from this directory.
3. Install the required packages: `npm install`
4. Adjust the configuration (or set the corresponding environment variables): `src/Config.ts`
5. Run an example: `node src/Example1.ts`

Example programs:

- `Example1.ts`: The minimal example from the README of the package.
- `Example2.ts`: An overview of the methods of the `ConnectionPlus` class.
